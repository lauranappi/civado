# Ci Vado

Tutti gli eventi di Bergamo (mostre, corsi, famiglie, serate) in un posto solo.

- `index.html`: l'app (HTML statico, nessuna dipendenza).
- `eventi.json`: i dati. Ogni evento ha uno `stato`: `controllato`, `controllare` (trovato in una sola fonte) o `da-confermare` (appuntamento ricorrente senza date 2026).
- Gli eventi hanno sempre il link alla fonte. Niente testi lunghi né immagini copiate.
